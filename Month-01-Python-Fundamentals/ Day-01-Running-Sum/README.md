# Day 01 >>(15.11.2026) - Running Sum of 1d Array

## Problem
Running Sum of 1d Array

## Platform
LeetCode

## Difficulty
Easy

## Input
[1, 2, 3, 4]

## Expected Output
[1, 3, 6, 10]

## Concepts Learned
- Python List
- For Loop
- Variable
- append() Method

## Logic
1. Start with total = 0
2. Create an empty result list.
3. Use a for loop.
4. Add each number to total.
5. Append total to result.

## Complexity
Time Complexity: O(n)
Space Complexity: O(n)
